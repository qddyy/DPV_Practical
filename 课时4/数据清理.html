数据清理

脏数据清洗

modeldata::deliveries 包含多条单一餐厅订单记录, 变量包括配送耗时 time_to_delivery, 下单时间 hour, 下单时星期几 day, 配送距离 distance, 以及 27 种菜品数量 item_01 ~ item_27.

deliveries_dirty 是其”脏”版本, 我们在其上演示重复值, 无效值与错误值三类问题的检测与处理.

重复值

完全相同的多条记录通常源于数据采集或合并时的失误, 直接用 dplyr::distinct() 即可去除.

若想先审视一下到底哪些行重复, janitor::get_dupes() 比 group_by() %>% filter(n() > 1) 更方便.

在此数据集中, 完全重复的记录几乎一定是脏数据, 因为下单时间与配送时间完全相同. 但在其他场景中, 也可能存在合法的重复观测 (如同一用户极短时间内多次购买同一商品).

无效值

无效值与分析目标无关, 或不符合字段含义, 如某些菜品数量是 NA, 应使用 dplyr::filter 去除:

也可使用 tidyr::drop_na() 一次性去除多列的 NA:

错误值

错误值是违反物理或基本逻辑约束的取值:

  • hour 应取 0~24, 大于 24 或小于 0 即为录入错误
  • time_to_delivery 应为正数, 负数可能是系统错误

dataReporter

检查脏数据中可能出现的问题往往是一项繁琐的工作. dataReporter 提供了一套一键式的自动化数据质量检查工具, 适合在数据清洗的初始阶段快速扫描全局问题.

其主要提供 summarize()/visualize()/check() 三个函数, 分别给出数据摘要、可视化分布与执行问题检测.

summarize() 给出每个变量的摘要统计 (类型、缺失数、分位数、最常见取值等), 为简洁起见只看三列:

visualize() 为每个变量绘制合适的图形 (数值型画直方图, 类别型画条形图):

check() 检查每个变量的常见问题, 包括离群值、唯一值过多、缺失编码异常等:

此外, 直接 makeDataReport() 就能生成一个包含这三部分的综合报告:

dataReporter::makeDataReport(deliveries_dirty, output = "html", replace = TRUE)

类似性质的 R 包还有很多, 如 DataExplorer. 这些工具的优点是快速, 但缺点是灵活性较差, 可能无法覆盖特定领域或特定数据集的特殊问题.

在实际使用中, 一个常见的需求是将领域知识注入数据清洗流程. 因此, 存在专门的数据质量检查工具包, 如 pointblank, assertr 等.

基于分布

单变量

Z 分数

Z 分数即每个数据点减去均值除以标准差, 得到一个表示偏离程度的标准化分数. 通常其绝对值超过 3 即视为离群. 可使用 base::scale() 计算:

我们画出直方图展示离群值在分布中的位置:

修正 Z 分数

Z 分数本身的均值与标准差本身就受离群值影响, 在重尾或污染数据下并不稳健. 修正 Z 分数改用中位数与 MAD 代替均值与标准差, 更加稳健, 常用阈值是 3.5. 可使用 R 中 stats::mad() 辅助计算 (其默认 constant = 1.4826 已经校正了正态分布下 MAD 与标准差的关系):

我们同样画出直方图展示修正 Z 分数的离群值位置, 并用虚线标出阈值:

箱线图

箱线图准则以四分位数与四分位距 (IQR) 划界: 落在下四分位数减 1.5 倍 IQR 与上四分位数加 1.5 倍 IQR 之外的点即视为离群. grDevices::boxplot.stats() 直接返回落在该区间之外的点:

使用 geom_boxplot() 可视化时, 默认会把离群点标成单独的点, 画在箱线之外.

多变量

椭圆包络

数据中每个点到分布中心的 马氏距离 衡量了它偏离中心的程度 (自动校正了各维度的尺度与相关性). 可使用 stats::mahalanobis() 直接计算.

马氏距离的平方在多元正态下近似服从卡方分布, 检测异常值时取 0.975 分位数为阈值即可.

可以使用 stat_ellipse() 画出马氏距离等高线 (椭圆), 以直观展示离群点的位置:

MCD

椭圆包络中, 均值与协方差矩阵本身受离群点影响 (经典统计量并不稳健, “蒙住眼”看一遍数据可能误把离群点拉进中心). MCD (Minimum Covariance Determinant) 在所有指定大小 \(h\) 的子集中, 选取协方差矩阵行列式最小者, 据此给出稳健的中心与散布估计.

R 中 robustbase::covMcd() 是其经典实现:

把之前的椭圆包络与 MCD 估计的椭圆叠在一起, 可以看到 MCD 椭圆更紧凑, 判定出的离群点更多.

  • \(h\) 越小, 抗污染能力越强 (理论上 \(h \approx n/2\) 时最大可承受约 50% 的污染), 但用来估计的样本少, 效率/精度低;
  • \(h\) 越接近 \(n\), 用的样本越多, 估计越光滑, 但越接近经典协方差, 越容易被离群点拉偏;

在 robustbase::covMcd() 里, 这一参数通过 alpha 指定 (\(h \approx \alpha n\)), 默认为 0.5.

下面同时拟合多个 alpha, 把对应的 0.975 椭圆叠在数据上观察其变化:

可以看到, alpha 从 0.5 增长到 1 的过程中, MCD 椭圆从一个紧贴主体的小椭圆, 逐步膨胀至与经典椭圆几乎重合.

基于距离/密度

LOF

LOF (Local Outlier Factor) 比较每个点的局部密度与其 k 近邻的局部密度, 显著低于邻居即视为离群. LOF 值接近 1 表示与邻居密度相当, 显著大于 1 即为局部离群. 由于 LOF 依赖距离, 不同量纲的变量应先标准化. 包 dbscan 提供经典实现:

由于 LOF 是连续分数, 我们用渐变色 + 点大小表示各观测的 LOF, 以下散点图中可见离群值具有较高的 LOF 分数

基于模型

孤立森林

孤立森林通过随机选择特征与切分点构建一组孤立树. 由于离群点稀疏且远离其他点, 通常只需较少的切分即可被”孤立”出来, 据此得到 0 到 1 之间的异常分数.

solitude 包是 Liu, Ting & Zhou 原始论文的经典实现, 接口为 R6 风格. 由于课件使用的 webR 环境不支持其内部对 ranger 的使用, 这里仅展示代码.

iso_model <- solitude::isolationForest$new(
    num_trees = 100, sample_size = 256, nproc = 1
)
iso_model$fit(deliveries_sub)

iso_scores <- iso_model$predict(deliveries_sub) %>% arrange(id)

deliveries_sub %>%
    mutate(
        iso = iso_scores$anomaly_score,
        is_outlier = iso > 0.6
    ) %>%
    count(is_outlier)

类似 LOF, 我们用颜色表示异常分数:

deliveries_sub %>%
    mutate(iso = iso_scores$anomaly_score) %>%
    ggplot(aes(distance, time_to_delivery, color = iso)) +
    geom_point(alpha = 0.7, size = 2) +
    scale_color_viridis_c(option = "magma", direction = -1)

isotree 包是孤立森林的另一个高性能实现, 同时也提供了更多变体实现.

单类支持向量机

One-class SVM 在 (核映射后的) 特征空间中寻找一个超平面, 把大部分数据点与原点分开, 落在另一侧的即视为离群. 参数 nu 大致控制离群比例的上界.

包 e1071 (libsvm 的 R 接口) 通过 type = "one-classification" 提供实现:

为直观看到 OCSVM 学到的边界, 我们在网格上预测一遍, 用填充色绘出决策区域:

nu 参数对决策边界的影响

nu 的几何含义有两条等价的表述: (1) 训练集中被判为离群的样本比例的上界; (2) 支持向量比例的下界. 实际效果是: nu 越小, 决策边界越紧地裹住数据主体外, 判出的离群点更少; nu 越大, 边界向内收缩, 判出的离群点更多.

我们在网格上对若干 nu 同时预测, 用分面图对比:

可以看到, 当 nu = 0.01 时几乎所有点都落在内点区; 而当 nu = 0.3 时, 模型把更多点判定为离群点.

核函数对决策边界的影响

kernel 决定决策边界在原始空间中的形状. 常用的有四种:

  • linear: 决策边界在原始空间中就是一条直线/超平面
  • polynomial: 多项式核, 边界为多项式曲面
  • radial (RBF, 默认): 高斯核
  • sigmoid: 双曲正切核

easystats

easystats 是一系列 R 包的集合, 旨在提供一个统一且一致的框架来在 R 中完成数据处理、建模、诊断、解释和可视化在内的完整分析流程. 它包含多个子包:

  • datawizard: 提供了各种数据处理工具, 如数据清洗、转换、可视化等.
  • performance: 提供了各种模型诊断工具, 包括离群值检测、模型拟合优度评估等.
  • see: 提供了与 performance 包紧密集成的可视化工具, 可以用来直观展示模型预测/诊断结果等
  • parameters: 用于提取和处理模型参数, 支持多种模型类型.
  • insight: 提供了一个统一的接口来提取模型信息, 如数据、参数、拟合统计量等.
  • effectsize: 用于计算和解释效应量, 支持多种统计测试和模型类型.
  • correlation: 提供了各种相关性分析工具, 包括相关矩阵、部分相关等.
  • modelbased: 提供了一个统一的接口来提取和处理模型结果, 支持多种模型类型.
  • report: 用于生成分析报告, 支持多种输出格式, 如 HTML、PDF 等.
  • bayestestR: 专注于贝叶斯统计分析, 提供了各种工具来解释和可视化贝叶斯模型的结果.

与 tidymodels 生态不同的是, easystats 更加关注统计模型而不是机器学习模型. 此外, 其主要提供的功能也更侧重于模型诊断和解释, 以及生成分析报告.

更多方法

  • CRAN Task View: AnomalyDetection: 社区维护的异常检测包索引, 覆盖时间序列、空间数据、流数据等场景.
